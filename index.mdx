`leading-zero-util` gives you precise control over the numeric padding in your filenames. Whether you're organising a directory of coding-challenge solutions, photo series, or any numbered file collection, one command brings everything into consistent alignment — or strips the zeros back out.

## What it does

<Steps>
  <Step title="Point it at a directory">
    Run `leading-zero-util` in any folder — or pass a path as the first argument. Every file and subdirectory whose name ends in digits is a candidate for renaming.
  </Step>
  <Step title="Choose add or remove">
    By default the tool **adds** one leading zero, normalising across all files so shorter numbers are padded to match the width of the longest one. Pass `--decrease` to strip zeros instead.
  </Step>
  <Step title="Control the count">
    Use `--number <N>` to add or remove more than one zero at a time. Use `--basic-add` to skip normalisation and pad each file independently.
  </Step>
  <Step title="Review the output">
    Every rename is printed to the terminal. Collisions (where the target name already exists) are skipped and reported so you never lose data.
  </Step>
</Steps>

## Quick example

```bash
# Before: problem-1.rs  problem-7.rs  problem-11.rs
leading-zero-util ./solutions
# After:  problem-01.rs  problem-07.rs  problem-11.rs
```
