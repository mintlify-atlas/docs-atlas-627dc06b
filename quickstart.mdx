`leading-zero-util` is a command-line tool that adds or removes leading zeros from the numeric suffixes of filenames and directory names. It operates on every entry in a directory whose name ends in ASCII digits, leaving everything else untouched. This guide walks you through installing the tool and running your first rename operation in four steps.

<Steps>
  <Step title="Install">
    The quickest way to get `leading-zero-util` is through Homebrew. Tap the formula repository and install in one go:

    ```bash
    brew tap KaonQuantum/leading-zero-util
    brew install leading-zero-util
    ```

    Homebrew also sets up shell completions for Bash, Zsh, and Fish automatically. For other install methods, see the [Installation](/installation) page.
  </Step>

  <Step title="Navigate to your directory">
    Change into the folder whose entries you want to rename. For example, if your problem set lives at `~/solutions`:

    ```bash
    cd ~/solutions
    ```

    Running the tool without a `PATH` argument always operates on the current working directory.
  </Step>

  <Step title="Add one leading zero (normalized)">
    Run `leading-zero-util` with no arguments. The tool inspects every entry in the current directory, finds the shortest numeric suffix, and pads all numeric filenames to that width plus one:

    ```bash
    leading-zero-util
    ```

    Given a directory that looks like this beforehand:

    ```
    # Before
    problem-1.rs   problem-7.rs   problem-11.rs
    ```

    The tool renames only the entries that are narrower than the target width, producing:

    ```
    # After
    problem-01.rs  problem-07.rs  problem-11.rs
    ```

    `problem-11.rs` is already at the target width and is left as-is.
  </Step>

  <Step title="Verify the output">
    `leading-zero-util` prints a line for each file it renames, followed by a summary once it finishes. A typical run looks like:

    ```
    Succesfully Renamed: problem-1.rs -> problem-01.rs
    Succesfully Renamed: problem-7.rs -> problem-07.rs
    Successfully changed 2 filenames.
    ```

    If no entries needed renaming, the tool prints `Changed zero filenames.` instead. No files are ever silently overwritten — if the destination name already exists, that rename is skipped and a warning is printed.
  </Step>
</Steps>

## Common tasks

The examples below cover the three most common workflows beyond the default. Pick the one that matches your situation.

<CodeGroup>

```bash Add two zeros to a specific path
# Add 2 leading zeros to every numeric entry in ~/solutions
leading-zero-util ~/solutions -n 2
```

```bash Remove one leading zero
# Strip 1 leading zero from every numeric entry in the current directory
leading-zero-util -d
```

```bash Add zeros without normalizing
# Prepend 1 zero to every numeric entry, regardless of other filenames
leading-zero-util -b
```

</CodeGroup>
